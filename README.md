# ATM-Simulator-System
📍 1. ATM Simulator System (Java + MySQL + HTML/CSS/JS)
🏦 ATM Simulator System

A web‑based ATM simulation application that supports account creation, secure login, balance enquiry, cash withdrawal, deposit, and transaction history. This project demonstrates frontend–backend communication, REST APIs, and database integration.

🚀 Features

Create new accounts

PIN‑based secure login

Balance enquiry

Cash withdrawal & deposit

View transaction history

Fully responsive UI

Backend deployed on Render

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript

Backend: Java, Spring Boot

Security: Spring Security (Custom JSON Authentication)

Database: MySQL

Hosting: Render

📡 API Base URL
https://atm-simulator-system.onrender.com/api/accounts
